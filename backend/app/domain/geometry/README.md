# Geometry Domain Module

## 📌 Purpose & Overview
Provides canonical 2D architectural BIM entity models, spatial boundary representations, and geometry validation contracts.

## 🏗️ Architectural Role
- **Domain Layer:** `backend/app/domain/geometry`
- **System Authority:** Deterministic Python owns geometry & state; AI proposes intent; PostGIS stores authoritative truth.

## 📁 Files & Responsibilities
- [`schemas.py`](file:///d:/Layouts%20AI/backend/app/domain/geometry/schemas.py): Pydantic v2 validation models (`ValidationResult`, `ConstraintViolation`, `ViolationSeverity`, `ViolationType`).
  - **Why needed:** Encapsulates hard (critical) and soft (warning) rule check outcomes generated by Shapely / GEOS geometry verification logic.
- [`entities.py`](file:///d:/Layouts%20AI/backend/app/domain/geometry/entities.py): Canonical 2D spatial BIM entity models (`WallEntity`, `DoorEntity`, `WindowEntity`, `ColumnEntity`, `BeamEntity`, `RoomEntity`, `CanonicalFloorPlan`).
  - **Why needed:** Decouples raw IFC/DXF file parser data into uniform Shapely-compatible spatial structures for computing door swing arcs, column obstacles, and window lighting preferences.

## 🔒 Security & Quality Invariants
- All state-changing operations are audited and validated.
- Strict typing and Pydantic/JSON Schema contracts are enforced.
- No direct LLM access to authoritative database writes or final coordinate math.
