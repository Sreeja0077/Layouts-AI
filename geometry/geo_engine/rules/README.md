# Physical Validation Rules Engine

## 📌 Purpose & Overview
Provides a deterministic architectural validation engine for space planning, furniture placement, clearance envelopes, circulation corridors, door swing arcs, and user requirements. Serves as the authoritative validation gate (`ValidationResult`) inspecting candidate layouts generated by AI or optimization algorithms.

## 🏗️ Architectural Role
- **Domain Layer:** `geometry/geo_engine/rules`
- **System Authority:** Deterministic Python owns geometry & state; AI proposes intent; PostGIS stores authoritative truth.

## 🔒 Fault Isolation & Determinism
- **Deterministic Violation IDs:** Violation IDs are derived deterministically using SHA-256 (`BaseRule.create_violation`). Identical input generates byte-identical violation IDs across repeated runs.
- **Fault Isolation:** Exceptions raised inside hard rules generate structured `CRITICAL_HARD` `RULE_EXECUTION_ERROR` violations; exceptions in soft rules generate `WARNING_SOFT` `RULE_EXECUTION_ERROR` violations. Rule evaluation never crashes or swallows exceptions silently.
- **Safe Deep-Copy Configuration:** `get_ruleset_config` uses `copy.deepcopy` to prevent custom config overrides from mutating global defaults.
